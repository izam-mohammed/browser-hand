## In short

browser-hand lets Claude Code drive the user's own Chrome profiles: pick a
profile, read pages, and click, type and scroll the way a person does. One
Rust binary is both the MCP server Claude talks to and the native messaging
host Chrome starts per profile; a TypeScript extension does the work inside
Chrome; a plugin brings the server and a skill. It runs on macOS and Linux
(tested) and Windows (compiled, never run), with Chrome, Chromium, Edge,
Brave and Vivaldi. It is built from source with `sh scripts/build.sh` and
the extension is loaded unpacked. Nothing has been released: no tag, no
GitHub release, no `CHANGELOG.md` (`README.md`, `git tag` is empty).

## What a person can use

### Driving Chrome

- Profiles, tabs, page reads, forms, input that moves like a person,
  screenshots and GIFs (`host/src/mcp.rs`, `extension/src/`;
  `plans/01-bridge.md` to `plans/04-skill.md`).
- Several Chromium browsers at once, with `<browser>:<dir>` profile names
  (`plans/14-chrome-parity-2.md`, `plans/15-browser-identity.md`).
- Windows: named pipes, registry registration, a launcher and upload checks,
  compiled only (`host/src/winos.rs`, `host/src/winsys.rs`;
  `plans/16-windows.md`).

### Recording and settings

- Record steps from a toolbar popup; Claude lists, reads and replays them
  (`extension/src/recorder.ts`, `extension/src/popup/`;
  `plans/05-record-steps.md`, `plans/08-recorder-popup.md`).
- A settings page saved by the host to `config.toml`
  (`extension/src/options/`, `host/src/config.rs`; `plans/06-settings.md`).

### Docs and site

- An mdBook book in `docs/book/`, a one-page site in `site/`, a README with
  a banner (`plans/10-site.md`, `plans/11-docs.md`; README rewrite in
  PR `#60`, not merged).

## Under the hood

- **Shape**: `host/` (Rust, `rmcp`), `extension/` (TypeScript, esbuild),
  `plugin/` (`.claude-plugin/plugin.json`, `.mcp.json`, one skill, the
  binary copied to `plugin/server/` and gitignored).
- **Versions**: `0.1.0` in `host/Cargo.toml`, `extension/package.json`,
  `extension/manifest.json` and `plugin/.claude-plugin/plugin.json`, kept
  by hand.
- **Packaging**: `scripts/package.sh` zips the extension for the Chrome Web
  Store; the store route is concluded, not released (`plans/07`).
- **Standards and CI**: `make check` (`docs/standards.md`);
  `.github/workflows/ci.yml` runs it on a self-hosted Linux runner because
  hosted minutes are blocked while the repository is private, and
  `security.yml` runs the shared gate.
