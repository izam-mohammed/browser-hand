## In short

browser-hand lets Claude Code drive the user's own Chrome profiles: pick a
profile, open and read pages, and click, type and scroll the way a person
does. A local Rust binary is both the MCP server Claude talks to and the
native messaging host Chrome starts per profile; a TypeScript extension
does the work inside Chrome. It is built and registered with
`sh scripts/build.sh`, the extension is loaded unpacked in each profile,
and Claude Code starts it through the plugin in `plugin/` (`README.md`).

## What a person can use

### Profiles and tabs

- Claude lists the Chrome profiles, selects one and works in its own
  `browser-hand` tab group (`host/src/profiles.rs`, `host/src/mcp.rs`,
  `extension/src/tabs.ts`; `plans/01-bridge.md`, PR `#1`).

### Reading pages and forms

- `read_page`, `find`, `get_page_text`, console and network reads,
  `form_input`, `javascript_tool`, `file_upload` and `browser_batch`
  (`extension/src/page/`, `extension/src/network.ts`;
  `plans/02-page-tools.md`, PR `#1`).

### Input that moves like a person

- `computer` clicks, types, scrolls and drags through the debugger protocol
  on curved paths, and takes screenshots (`extension/src/humane/`,
  `extension/src/input.ts`, `extension/src/screenshot.ts`;
  `plans/03-humane-input.md`, PR `#1`). The cursor is virtual: nothing on
  the page shows where it is.

### GIFs, the skill and the plugin

- `gif_creator`, the `browser-hand` skill and the plugin
  (`host/src/gif.rs`, `plugin/skills/browser-hand/SKILL.md`;
  `plans/04-skill.md`, PR `#1`).

### Recording steps

- The toolbar button (or Alt+Shift+R) records steps; Claude lists, reads,
  deletes and replays them (`extension/src/recorder.ts`,
  `extension/src/replay.ts`, `host/src/tools/recording.rs`;
  `plans/05-record-steps.md`, PRs `#3`, `#14`).

### Settings

- One options page for pace, sessions, blocked and read-only sites,
  capture and the debugger, saved by the host in
  `~/.config/browser-hand/config.toml` (`extension/src/options/`,
  `host/src/config.rs`; `plans/06-settings.md`, PRs `#4`, `#12`).

### Development helpers

- `browser-hand reload`, `scripts/package.sh` and
  `docs/store-listing.md` (PRs `#13`, `#15`).

### Repository

- Dependabot, a security policy and an MIT licence (`.github/dependabot.yml`,
  `SECURITY.md`, `LICENSE`; `plans/12-repo-hygiene.md`, PRs `#22`, `#24`).

## Under the hood

- **Shape**: `host/` is one Rust crate (MCP over stdio through `rmcp`, the
  native host, a Unix socket per profile); `extension/` is a Manifest V3
  extension bundled by esbuild; the wire format is `docs/protocol.md`, with
  TypeScript types generated by ts-rs into `extension/src/wire.gen.ts`.
- **Data**: `config.toml` owned by the host; recordings in each profile's
  extension storage. No database.
- **Integrations**: Chrome extension APIs, the debugger protocol, native
  messaging, the MCP spec and `rmcp` (`docs/external/`); proofs in
  `scripts/prove/`.
- **Reference**: `reference/claude-in-chrome/` describes Claude in Chrome
  as of 17/10/2026 (22 tools, extension 1.0.101) on `main`; the PR this
  snapshot ships with updates it to Claude Code 2.1.325 and extension
  1.0.107 (20 tools).
- **Standards and CI**: `docs/standards.md`. `.github/workflows/ci.yml` runs
  on every PR and push to `main`, on the laptop runner since PR `#21`.
