## In short

browser-hand lets Claude Code drive the user's own Chrome profiles on
macOS: pick a profile, open and read pages, and click, type and scroll the
way a person does. A local Rust binary is both the MCP server Claude talks
to and the native messaging host Chrome starts per profile; a TypeScript
extension does the work inside Chrome. It is built and registered with
`sh scripts/build.sh`, the extension is loaded unpacked in each profile,
and Claude Code starts it through the plugin in `plugin/` (`README.md`).

## What a person can use

### Profiles and tabs

- Claude lists the Chrome profiles, selects one (opening it with Chrome's
  command line when closed) and works in its own `browser-hand` tab group
  (`host/src/profiles.rs`, `host/src/mcp.rs`, `extension/src/tabs.ts`;
  landed in `plans/01-bridge.md`, PR `#1`).

### Reading pages and forms

- `read_page`, `find`, `get_page_text`, console and network reads,
  `form_input`, `javascript_tool`, `file_upload` and `browser_batch`
  (`extension/src/page/`, `extension/src/network.ts`; landed in
  `plans/02-page-tools.md`, PR `#1`).

### Input that moves like a person

- `computer` clicks, types, scrolls and drags through the debugger protocol
  on curved, minimum-jerk paths, and takes screenshots
  (`extension/src/humane/`, `extension/src/input.ts`,
  `extension/src/screenshot.ts`; landed in `plans/03-humane-input.md`,
  PR `#1`). Reading tools never attach the debugger (PR `#8`).

### GIFs, the skill and the plugin

- `gif_creator` records a session as an animated GIF, and the
  `browser-hand` skill and plugin install it all (`host/src/gif.rs`,
  `plugin/skills/browser-hand/SKILL.md`; landed in `plans/04-skill.md`,
  PR `#1`).

### Recording steps

- The toolbar button (or Alt+Shift+R) records the person's steps, and
  Claude lists, reads, deletes and replays them
  (`extension/src/recorder.ts`, `extension/src/replay.ts`,
  `host/src/tools/recording.rs`; landed in `plans/05-record-steps.md`,
  PR `#3`; replay brings its tab forward, PR `#14`).

### Settings

- One options page sets pace, sessions, blocked and read-only sites,
  capture and the debugger for every profile; the host saves
  `~/.config/browser-hand/config.toml` (`extension/src/options/`,
  `host/src/config.rs`, `extension/src/site-rules.ts`; landed in
  `plans/06-settings.md`, PRs `#4` and `#12`).

### Development helpers

- `browser-hand reload` reloads the extension in every connected profile,
  and `scripts/build.sh` calls it (`host/src/reload.rs`; PR `#13`).
- `scripts/package.sh` packs the extension zip for the Chrome Web Store,
  and `docs/store-listing.md` holds the listing (PR `#15`,
  `plans/07-install-extension.md` Phase 2, partly ticked).

### README

- A minimal README with a light and dark banner near the top
  (`README.md`, `assets/banner-light.svg`, `assets/banner-dark.svg`;
  PR `#19`).

## Under the hood

- **Shape**: `host/` is one Rust crate (MCP over stdio through `rmcp`, the
  native host, a Unix socket per profile); `extension/` is a Manifest V3
  extension bundled by esbuild (`extension/build.mjs`); the wire format is
  `docs/protocol.md`, with TypeScript types generated from Rust by ts-rs
  into `extension/src/wire.gen.ts`.
- **Data**: `config.toml` owned by the host; recordings in each profile's
  extension storage (`README.md` § How to record). No database.
- **Integrations**: Chrome extension APIs, the debugger protocol and native
  messaging, the MCP spec and `rmcp`, each documented in `docs/external/`;
  proofs in `scripts/prove/`.
- **Standards and CI**: `docs/standards.md` (types, vitest, cargo test,
  build). `.github/workflows/ci.yml` runs on every PR and push to `main`:
  `cargo fmt --check`, `cargo clippy -D warnings`, a release build and
  `cargo llvm-cov --fail-under-lines 70` for the host; `tsc`, the build and
  `vitest --coverage` with a 65 % lines floor (`extension/vitest.config.mjs`)
  for the extension. Actions are pinned by tag, not by commit SHA. No
  dependency audit, secret scan, static analysis, TypeScript lint or
  formatter runs anywhere, and the shared gate in `izam-mohammed/.github`
  is not called.
